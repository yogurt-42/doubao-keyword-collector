# 豆包关键词资料采集器 —— 下载与安装指南

> 本文档面向第一次使用 GitHub、不熟悉命令行的普通用户。
> 如果你只是想在 Windows 上用这个软件，按下面的步骤操作即可。

---

## 下载前须知

- **不需要注册 GitHub 账号**，也不需要安装 Python。
- 每个 Release 会提供两个 Windows 版本：

| 版本 | 文件名示例 | 特点 | 推荐人群 |
| --- | --- | --- | --- |
| 单文件版 | `AI信源采集工具-v1.0.0.exe` | 只有一个文件，下载完双击就能用 | 想省事、偶尔用一次 |
| 便携版 | `AI信源采集工具-v1.0.0-便携版.zip` | 需要解压，但启动速度更快 | 经常使用、对速度敏感 |

> 两个版本功能完全一样，区别只在“启动速度”和“文件个数”。

---

## 方法一：用浏览器下载（推荐）

### 1. 打开下载页面

在浏览器地址栏输入：

```text
https://github.com/yogurt-42/doubao-keyword-collector/releases
```

### 2. 找到最新版本

页面会列出所有版本，**最上面的就是最新版**，例如 `v1.0.0`。

点击版本标题进入详情页。

### 3. 展开附件列表

在页面下方找到 **Assets** 区域，点击它展开文件列表。

### 4. 下载对应版本

- 想简单省事 → 下载 `AI信源采集工具-v1.0.0.exe`
- 想启动更快 → 下载 `AI信源采集工具-v1.0.0-便携版.zip`

下载按钮就在文件名的右边。

### 5. 运行软件

**单文件版**：

1. 下载完成后，在“下载”文件夹里找到 `AI信源采集工具-v1.0.0.exe`。
2. 双击运行。
3. 如果 Windows 弹出“Windows 已保护你的电脑”，点击 **“更多信息” → “仍要运行”**。

**便携版**：

1. 下载完成后，在“下载”文件夹里找到 `AI信源采集工具-v1.0.0-便携版.zip`。
2. 右键点击该文件 → **“全部解压缩...”** → 选择解压位置（例如桌面或 D 盘）。
3. 打开解压出来的文件夹。
4. 双击里面的 `AI信源采集工具.exe`。

## 方法二：用命令行下载（适合熟悉 cmd / PowerShell 的用户）

### 下载单文件版（启动慢）

在 PowerShell 或命令提示符里输入：

```powershell
curl -L -o "AI信源采集工具-v1.0.0.exe" "https://github.com/yogurt-42/doubao-keyword-collector/releases/download/v1.0.0/AI信源采集工具-v1.0.0.exe"
```

### 下载便携版（启动快）

```powershell
curl -L -o "AI信源采集工具-v1.0.0-便携版.zip" "https://github.com/yogurt-42/doubao-keyword-collector/releases/download/v1.0.0/AI信源采集工具-v1.0.0-便携版.zip"
```

下载完成后：

- 单文件版直接双击运行。
- 便携版需要先解压，再运行里面的 `AI信源采集工具.exe`。

## 常见问题

### 1. 双击 exe 后很久才出现窗口？

这是 **单文件版** 的正常现象。它启动时需要把程序文件解压到临时目录，第一次可能慢 3~8 秒。

如果你希望启动更快，请下载 **便携版**。

### 2. 杀毒软件提示风险？

本软件没有数字签名，部分杀毒软件可能会误报。你可以选择：

- 点击“更多信息” → “仍要运行”。
- 或在杀毒软件里把该 exe 加入白名单。

### 3. 我的数据保存在哪里？

默认保存在：

```text
%LOCALAPPDATA%\DoubaoAccountManager
```

也就是 `C:\Users\你的用户名\AppData\Local\DoubaoAccountManager`。

采集结果存在里面的 `research.sqlite3` 文件中，建议定期备份。

### 4. 需要安装 Python 吗？

**不需要。** 下载 exe 版本即可直接运行。

只有你想从源码运行或参与开发时，才需要安装 Python。

### 5. 下载页面全是英文，看不懂？

只需要认准这几个词：

- **Releases** = 发布版本
- **Assets** = 附件 / 下载文件
- **Latest** = 最新

或者直接记住下载地址：

```text
https://github.com/yogurt-42/doubao-keyword-collector/releases
```

## 开始使用

1. 运行软件。
2. 点击顶部 **“账号环境”** 页签，创建一个账号，并在打开的豆包页签中登录。
3. 回到 **“新建采集”**，粘贴或导入关键词。
4. 设置采集间隔，选择账号，创建任务。
5. 在 **“采集结果”** 查看数据，或导出 Excel。

更详细的操作说明请参考 [`README.md`](./README.md)。

## 如果下载链接打不开

GitHub 在国内部分地区访问较慢，可以尝试：

- 使用手机热点下载。
- 在浏览器安装访问 GitHub 的加速插件。
- 请朋友帮忙下载后传给你。

软件本身不需要联网即可运行（采集豆包时自然需要网络）。
